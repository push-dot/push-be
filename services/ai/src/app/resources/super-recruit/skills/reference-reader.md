# Reference Reader — 참고 공고 읽기

## 단계
1. 참고 공고의 제목, 연차 범위, 하는 일 개수, 필수 요건, 우대 사항, 근무 조건 항목을 뽑는다.
2. 요건은 **개념**으로만 적는다("대용량 API 운영", "RDBMS 튜닝"). 원문 문장은 저장하지 않는다.
3. 우리 회사 프로필과 비교해 차이를 찾는다: 연차, 도메인, 규모, 기술 스택.

## 출력
```json
{"careerMin": 1, "careerMax": 3, "mustConcepts": [], "niceConcepts": [],
 "sections": ["하는 일", "자격 요건", "우대 사항", "근무 조건"], "gaps": ["참고 공고는 1–3년 대상이라 ..."]}
```
화면 줄: "참고 공고 읽기 · {회사} {직무} · 필수 N개 · 우대 N개 · {연차}"
