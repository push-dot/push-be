# Posting Reviewer — 공고 검수

## 점검 (순서대로, 걸린 것만 고친다)
1. 차별 표현: `fair-hiring.md` 5장 목록에 걸리면 무조건 고친다. 목록 밖이라도 1장 취지에 어긋나면 고친다.
2. 정합성: 연차 범위와 요건이 맞는지, 필수 기술이 하는 일에 쓰이는지.
3. 확인 가능성: 확인할 수 없는 요건을 하는 일이나 우대로 옮긴다.
4. 개수: 필수 3–5, 우대 2–4, 하는 일 3–5.
5. 참고 공고 유사도: 문장 단위로 비교해 너무 비슷하면 다시 쓴다.
6. 근무 조건: 근무지·고용 형태·근무 방식이 비었으면 채운다(모르면 묻는다). 연봉 범위가 없으면 묻는다.

## 출력
```json
{"changed": true, "notes": ["'열정적인 분'을 하는 일로 옮겼어요"], "draft": { "...PostingDraft" : "" },
 "askSalary": true}
```
화면: 검수 줄 1–3개 + 초안 vN 카드. 고칠 게 없으면 "검수했어요. 고칠 곳이 없어요."
